# AI Pac-Men Project

This project was completed as part of the **Artificial Intelligence** course at **Université d'Évry Paris-Saclay**, taught by **Prof. Nazim Agoulmine**, during the 2025–2026 academic year.

The objective is to solve a multi-agent Pac-Men gathering problem using search algorithms. The project includes implementations of **DFS** and **A\***, complexity analysis, heuristic admissibility proofs, and performance comparisons.

**Lecturer:** Prof. Nazim Agoulmine  
**Completed by:** Bitchiko Gularashvili

## Repository Contents

- `pacmen_solver.py` — core implementation of the problem and algorithms
- `demo.py` — demonstrations and benchmarks used for the project
